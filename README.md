# Mahfa

## مدیر کل (سوپرادمین)
- هنگام اولین اجرای سرور، حساب مدیر کل ساخته می‌شود.
- نام کاربری: `SUPERADMIN_USERNAME` (پیش‌فرض `superadmin`)
- رمز: `SUPERADMIN_PASSWORD`؛ اگر ست نشود یک رمز تصادفی فقط یک بار در لاگ سرور چاپ می‌شود.
- بعد از اولین ورود، رمز را با دکمه‌ی کلید عوض کنید.

## تم‌ها
مدیر کل از تب «مدیر کل» → «تم سایت» تم را برای همه عوض می‌کند: عادی، هالووین، کریسمس، یلدا، نوروز، روز معلم، رمضان، پاییز.
هر تم یک فایل در `public/` است (مثلاً `yalda.html`) و مستقیم هم باز می‌شود. متغیر `SITE_THEME` فقط مقدار اولیه است.

## اعلان همگانی
معلم یا مدیر کل از تب «مدیریت» اعلان می‌نویسد؛ بالای صفحه‌ی همه‌ی کاربران نشان داده می‌شود و هر کس می‌تواند ببندد.

## اعلان پاسخ
وقتی معلم به پیام دانش‌آموز پاسخ دهد، روی تب «پیام» عدد قرمز می‌آید (هر ۶۰ ثانیه خودکار بروز می‌شود).
